# 🍙 My Dotfiles — Arch Linux & Hyprland

Personal configuration files (dotfiles) for my Arch Linux desktop environment powered by the **Hyprland** Wayland compositor.

---

## 🖥️ Overview

- **OS:** Arch Linux
- **Window Manager:** [Hyprland](https://hyprland.org/) (Wayland compositor)
- **Status Bar:** [Waybar](https://github.com/Alexays/Waybar) with dynamic themes
- **Terminal Emulator:** [Kitty](https://sw.kovidgoyal.net/kitty/)
- **App Launcher & Menus:** Rofi (Wayland fork)
- **Theme Engine:** Wallbash / Pywal dynamic color generation from wallpapers
- **System Info:** Neofetch

---

## 📂 Repository Structure

```
.config/
├── hypr/               # Hyprland core configuration, window rules, keybinds
├── kitty/              # Kitty terminal fonts, opacity, and color schemes
├── waybar/             # Waybar layouts, modules, and theme styling
│   └── themes/         # Tokyo-Night, Catppuccin, Gruvbox, Rose-Pine, etc.
└── neofetch/           # Neofetch system info config and ASCII art
```
